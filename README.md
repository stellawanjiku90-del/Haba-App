# Haba — loan application prototype

A responsive, static prototype showing a phone sign-up, demo OTP, password setup, personal and work details, two references, consent review, and a sample loan-limit and fee screen.

## Run locally

Open `index.html` in a browser, or serve this folder with any static file server. At the demo OTP screen, enter `246810`.

## Prototype boundaries

This is a front-end demonstration only. It sends no OTP, stores no form entries, reads no SMS, contacts, call logs, or device data, checks no credit history, makes no real eligibility decision, and takes no payment. Form data remains in page memory until reload or exit.

The sample limit is fixed at 25,000 in the selected currency. The displayed 500–100,000 range and 100 local-currency activation fee are illustrative. A real product needs country-specific licensing and consumer disclosures, an appropriately licensed lending partner, secure OTP and application services, a reviewed affordability/credit model, explicit permission and data-minimization controls, reference-contact notices, and a secure payment integration. Confirm that an activation fee is permitted and disclose the total cost of credit before launching in each market.
