# Haba — loan estimate prototype

A responsive, static landing page and repayment estimator concept for a pan-African audience. It runs entirely in the browser and does not submit, store, or transmit personal information.

## Run locally

Open `index.html` in a browser, or serve this folder with any static file server.

## Important

Haba is a concept, not a lender or loan offer. The calculator uses an illustrative 16% flat annual rate. Rates, fees, eligibility, consumer protections, and licensing requirements differ across countries. Before launching real applications, partner with appropriately licensed providers in each market and add the applicable disclosures, privacy controls, and secure application process.
